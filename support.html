Frequently Asked Questions

Where is my data stored?
Lago uses local storage by default. If you choose cloud backup, Apple Devices Sync, All Devices Sync, or network-based Smart Input, the relevant data is sent to the provider needed for that feature.

How do I backup my data?
Open Lago's Sync or Backup settings. Supported Apple devices can use iCloud, while Android can use Google Drive. All Devices Sync uses your Lago account to keep eligible data aligned across supported platforms.

Is my data secure?
Lago uses supported device security, optional biometric app locking, encrypted network connections, authenticated cloud access, and Firebase security controls. No storage or transmission method can guarantee absolute security.

How do I delete my sync account and cloud data?
On Android, open Settings → Manage Backups → Cloud Sync → Delete Lago account. On supported Apple versions, use Settings → Manage Backups → Real-Time Sync → Delete Lago Account. This permanently deletes the Lago sign-in and All Devices Sync cloud data. Local data, cloud backups, and subscriptions remain. If the option is unavailable, use our Account and Data Deletion page.

Adding Transactions with Siri

Lago 1.7 added voice and Shortcuts support, so you can log expenses and income without opening the app.

Siri voice
Say "Hey Siri, add expense to Lago" (or "Add income to Lago"). Siri will ask for the amount, then which account, then the optional merchant and category.

Shortcuts app
Open the Shortcuts app, tap +, search "Lago", and choose Add Expense or Add Income. Fill the fields, then run the action.

Spotlight
Swipe down on the Home Screen, type "add expense", and tap the action that appears.

Tip: voice transactions run entirely on-device — no internet, no servers, no audio ever leaves your phone.

Backup & Restore

Lago creates encrypted ZIP backups in your iCloud Drive so you can move to a new device or recover from accidents.

Automatic backups
Settings → Manage Backups. Toggle "Automatic Backups" on. Backups run silently in the background while your phone is charging.

Create a backup now
Settings → Manage Backups → "Create Backup Now". The zip lands in iCloud Drive under Lago.

Restore backups
Open Lago on the new device. Accept the iCloud backup prompt on first launch, or go to Settings → Manage Backups, tap any backup, and choose Restore.

Tip: backups include accounts, transactions, budgets, recurring rules, and your profile picture. Each device keeps its own retention window, so backups from your other devices stay visible too.

Setting Up Budgets

Budgets help you stay on track. Each budget is tied to a specific ledger and category, with optional threshold alerts.

Create a budget
Open the Budget tab, tap a category, and set the monthly amount. Repeat for each category you want to track.

Get alerts before you overspend
Settings → Notifications → Budget Threshold (Pro). Choose 80%, 90%, or 100% to receive a notification when you cross that mark.

Personal vs Business
Each ledger has its own budgets. Switch ledgers via the ledger menu at the top of the Budget tab — numbers stay scoped to whichever ledger is active.

Tip: Lago 1.7 fixed a bug where a budget's percentage could exceed 100% from spending in other ledgers. Each ledger now keeps its own books.

Recurring Transactions

For bills, salaries, or subscriptions that repeat. Lago can either auto-post them on the day they're due, or remind you to confirm.

Create a recurring rule
Transactions tab → Recurring → +. Set the amount, account, category, frequency (weekly, monthly, etc.), and start date.

Choose the mode
"Auto-post" inserts the transaction automatically on the due date. "Reminder" sends a notification asking you to confirm before posting.

Stop or change a rule
Tap a rule in the Recurring list to edit, pause, or delete it. Past auto-posted transactions are kept; only future scheduling changes.

Tip: recurring rules sync across iPhone, iPad, and Mac when iCloud sync is on, so you only set them up once.
